# AutoPrint / QRPrint — Unused & Archived Files Repository

This directory contains legacy standalone repositories, historical snapshots, duplicate modules, and deprecated scripts that have been safely archived during the project reorganization.

## Preservation Guarantee
* **Zero Data Loss**: No files were permanently deleted.
* **Integrity**: Original folder structures and code files are preserved intact.
* **Reversibility**: Any component can be referenced, inspected, or restored at any time.

## Directory Structure
* `old-standalone-repos/`: Standalone customer and merchant web repositories prior to unified workspace architecture.
* `old-snapshots/`: Previous development snapshots (`AUTOPRINT fixed`).
* `old-scripts/`: Legacy startup `.bat` and `.vbs` scripts superseded by the `installer/` wizard and `scripts/` suite.
* `duplicate-files/`: Duplicate `shared` types and old doc archives.
* `migration-manifest.json`: Full machine-readable record of all archived items with reasons and timestamps.

## Restoring a File
To restore any file or folder back to the active project, simply copy the item back to the active workspace directory as specified in `migration-manifest.json`.
