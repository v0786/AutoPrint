# AutoPrint — First-Time PC Setup Guide

[See docs/07-deployment/FIRST_TIME_PC_SETUP.md for the complete 20-step guide]

This document explains everything required to install and configure AutoPrint on a fresh PC for Xerox and copy shop owners.

---

## 1. Quick Requirements
* **Operating System**: Windows 7 SP1 (64-bit), Windows 8, Windows 10, or Windows 11.
* **Memory**: Minimum 2 GB RAM (4 GB recommended).
* **Disk**: 2 GB free disk space.
* **Printers**: Any Windows-supported USB or network laser/inkjet printer.
* **Network**: Local shop Wi-Fi router (internet optional).

---

## 2. Setup Process Overview
1. Run `AutoPrint-Setup.exe`.
2. Follow the First-Run Setup Wizard at `http://localhost:8000`:
   * Set admin username and password.
   * Enter shop name, country, currency, and language.
   * Auto-discover printers and choose default printer.
   * Set paper pricing rates.
   * Test PageKite or keep local Wi-Fi mode.
   * Print counter standee Shop QR code.
   * Save emergency recovery code.
3. Perform test print from customer smartphone.
